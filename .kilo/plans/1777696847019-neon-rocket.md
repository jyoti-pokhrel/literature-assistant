# Interactive Gap Explorer

## Overview

Replace the static results display with an interactive exploration experience. The centerpiece is a D3.js-powered UMAP cluster map where papers are clickable dots, linked to a detail panel that shows gaps, supporting papers, and evidence. Users can filter/sort gaps and papers, and clicking any element cross-highlights related items across all views.

## Current State

- **Backend** already returns all needed data: `clusters[]` contains per-paper `{x, y, title, year, venue, cluster_id}` and per-cluster `{gaps[], top_terms[]}`. Gap objects have `cluster_id`, `citations[]`, `score_breakdown`, and `confidence_score`.
- **Frontend** renders UMAP as a static base64 PNG image, gaps as expandable cards, clusters as simple cards, and papers as a flat list.
- **No new API endpoints needed** — all data for interactivity is already in the `SynthesisResponse`.

## Architecture Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Chart library | D3.js (CDN) | Full control over scatter, zoom, tooltips; already using CDN approach for Alpine/GSAP |
| Detail panel | Slide-in side panel | Keeps context of the map visible while exploring details |
| State management | Alpine.js store | Already in use; add `explorer` sub-state for selection/filter state |
| New files | 2 JS files + 1 CSS file section | `clusterMap.js` (D3 component), `gapExplorer.js` (Alpine component with panel + filters) |

## Implementation Plan

### 1. Add D3.js dependency
- Add `<script src="https://cdn.jsdelivr.net/npm/d3@7/dist/d3.min.js"></script>` to `index.html`
- No npm install needed — CDN like existing Alpine.js/GSAP

### 2. Create interactive UMAP cluster map (`frontend/js/d3/clusterMap.js`)

Replace the static `<img>` for `umap_scatter` with a D3-rendered SVG scatter plot:

- **SVG scatter plot** with zoom/pan (`d3.zoom()`)
- Each paper rendered as a circle, colored by cluster (`d3.scaleOrdinal(d3.schemeTableau10)`)
- Cluster regions shown as convex hull outlines (semi-transparent)
- **Hover**: tooltip showing paper title, year, venue
- **Click paper dot**: dispatch custom event `paper:select` with paper data
- **Click cluster region**: dispatch `cluster:select` with cluster data
- **Highlight mode**: when a gap is selected externally, highlight its supporting papers on the map (pulse animation + opacity dim on others)
- **Responsive**: resize on container resize via `ResizeObserver`
- Expose `window.ClusterMap` with `render(container, clusters)`, `highlightPapers(paperIds)`, `clearHighlight()`, `destroy()`

**Data source**: Use `clusters()` from the existing `resultsPage` component — each cluster already has `papers[].x`, `papers[].y`.

### 3. Create gap explorer Alpine component (`frontend/js/alpine/components/gapExplorer.js`)

New `x-data="gapExplorer()"` component that wraps the existing gaps + clusters + viz sections:

**Filter bar** (above the gap list):
- Confidence score range slider (min 0.0 – max 1.0)
- Cluster filter dropdown (populated from cluster IDs)
- Text search input (filters gap titles/descriptions)
- Sort dropdown: "Confidence (high→low)", "Confidence (low→high)", "Cluster"
- Active filter pills with clear button

**Gap list** (enhanced from current):
- Existing gap cards stay, but add:
  - `@click` handler to select gap → opens detail panel + highlights supporting papers on map
  - Visual indicator showing which cluster each gap belongs to (colored dot matching cluster color)
  - Subtle border highlight when gap is selected

**Paper list** (enhanced from current):
- Add cluster color indicator per paper
- `@click` handler to select paper → opens detail panel + highlights dot on map
- Dim papers not matching current filters

### 4. Create detail side panel

A slide-in panel (`position: fixed; right: 0`) that shows when a gap or paper is selected:

**When a gap is selected:**
- Gap title, description, what_fails, missing_piece, why_it_exists
- Proposed direction
- Full score breakdown (visual bars for each dimension)
- Supporting papers list (clickable → selects that paper, highlights on map)
- Citation validation status
- Close button

**When a paper is selected:**
- Paper title, year, venue, source
- Link to original paper
- List of gaps this paper supports (clickable → selects that gap)
- Cluster membership (with color)
- Close button

**When a cluster is selected:**
- Cluster ID, paper count, top terms
- List of papers in cluster (clickable)
- List of gaps in cluster (clickable)

### 5. Wire cross-highlighting

All interactions should cross-highlight:
- **Select gap** → highlight supporting papers on D3 map + scroll to gap in list
- **Select paper on map** → open paper detail panel + highlight paper in paper list
- **Select cluster on map** → filter gap list to that cluster's gaps + open cluster detail panel
- **Filter gaps** → dim unmatched papers on D3 map

Use Alpine.js `$dispatch` / `@paper:select.window` pattern for loose coupling between D3 map and Alpine components.

### 6. Add explorer state to Alpine store

Add to `appStore.js`:
```js
explorer: {
  selectedGapId: null,
  selectedPaperId: null,  
  selectedClusterId: null,
  panelOpen: false,
  panelType: null, // 'gap' | 'paper' | 'cluster'
  filters: {
    minConfidence: 0,
    maxConfidence: 1,
    clusterId: null,
    searchText: '',
    sortBy: 'confidence_desc'
  }
}
```

### 7. CSS additions

Add to `frontend/css/style.css`:
- `.explorer-layout` — CSS grid layout: map on left, gap list on right (or stacked on mobile)
- `.cluster-map-container` — aspect-ratio container for D3 SVG
- `.detail-panel` — slide-in panel styles with backdrop
- `.filter-bar` — horizontal filter strip
- `.gap-card.is-selected`, `.paper-card.is-selected` — selection highlight states
- `.gap-card .cluster-dot` — colored dot indicator
- `.paper-dot--highlighted` — D3 circle highlight animation
- Responsive breakpoints: map stacks above lists on `<= 1024px`

### 8. Update `index.html`

- Add D3.js `<script>` tag
- Add `clusterMap.js` and `gapExplorer.js` script tags
- Replace the current viz/gaps/clusters/papers sections in `#thread-view` with the new `x-data="gapExplorer()"` component that contains:
  - Filter bar
  - Two-column layout: D3 map + gap/paper lists
  - Detail side panel (hidden by default)
- Keep the existing static visualizations (confidence bars, year distribution, etc.) below the explorer as a "More charts" collapsible section

## Non-Goals (out of scope)

- No backend API changes needed
- No user annotations/notes (excluded per user choice)
- No changes to the synthesis pipeline or data model
- No new npm dependencies (D3 via CDN)

## Risks & Mitigations

| Risk | Mitigation |
|------|-----------|
| D3 SVG performance with many papers (>100 dots) | Use `<canvas>` fallback if needed; current max is 20 papers so this is unlikely |
| Alpine + D3 event coordination complexity | Use custom DOM events (`dispatchEvent`) for loose coupling; avoid tight binding |
| Mobile UX for interactive map | Stack layout on mobile; detail panel becomes full-screen overlay |
| Large CSS additions to single file | Use BEM-style naming (`.explorer-*`) to isolate styles |
